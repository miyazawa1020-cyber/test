# シンプルなログインアプリ

Node.js + Express を使用した簡単なログイン・ユーザー管理アプリケーションです。

## 機能

- ✅ ユーザー登録（パスワード暗号化）
- ✅ ログイン機能
- ✅ セッション管理
- ✅ ログアウト機能
- ✅ ダッシュボード
- ✅ SQLite データベース

## インストール

### 1. リポジトリをクローン

```bash
git clone https://github.com/miyazawa1020-cyber/test.git
cd test
```

### 2. 依存パッケージのインストール

```bash
npm install
```

### 3. アプリケーション起動

```bash
npm start
```

または開発用（自動リロード）：

```bash
npm run dev
```

## 使用方法

1. ブラウザで `http://localhost:3000` にアクセス
2. **「登録」ページでアカウントを作成**
   - ユーザー名を入力
   - 6文字以上のパスワードを入力
3. **ログイン**
   - 作成したアカウントでログイン
4. **ダッシュボード**
   - ログイン後のウェルカムページが表示されます

## ファイル構成

```
.
├── server.js              # メインサーバーファイル
├── package.json           # 依存パッケージ管理
├── login.db              # SQLite データベース（自動生成）
├── views/
│   ├── login.ejs         # ログインページ
│   ├── register.ejs      # 登録ページ
│   └── dashboard.ejs     # ダッシュボード
└── public/
    └── style.css         # スタイルシート
```

## セキュリティ機能

- bcryptjs によるパスワード暗号化
- セッション管理
- SQL インジェクション対策（プリペアドステートメント使用）

## 使用技術

- **Express.js** - Webフレームワーク
- **SQLite3** - データベース
- **bcryptjs** - パスワード暗号化
- **EJS** - テンプレートエンジン
- **express-session** - セッション管理

## デフォルト設定

- ポート：`3000`
- データベース：`./login.db`
- セッションタイムアウト：24時間

## カスタマイズ

`server.js` の以下の部分を編集してカスタマイズできます：

- ポート番号：`const port = 3000;`
- セッション秘密鍵：`secret: 'your-secret-key'`
- セッション有効期限：`maxAge: 1000 * 60 * 60 * 24`
